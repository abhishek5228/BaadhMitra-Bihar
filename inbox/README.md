# Bulletin inbox

Put the CWC daily flood bulletin PDFs here (save each one from cwc.gov.in in your browser, then GitHub: **Add file → Upload files**). Each upload runs the `cwc-feed` job, which reads the newest bulletin by date and updates `data/cwc-latest.json`. See [`docs/CWC-FEED.md`](../docs/CWC-FEED.md).
